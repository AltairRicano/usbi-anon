Componente que combina la navegación cliente de `react-router-dom` con los estilos visuales de `Button`. Evita la anidación inválida de `<a>` dentro de `<button>`, produciendo un único elemento `Link` interactivo en el DOM.

## Funciones

### LinkButton
**Elaboración:** 2026-09-19 | **Actualización:** 2026-09-19

Renderiza un componente `Link` estilizado mediante `buttonClasses` para simular visualmente la apariencia y comportamiento de un botón.
