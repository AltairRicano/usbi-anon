Componente de botón reutilizable construido sobre la etiqueta nativa `<button>`. Permite parametrizar variantes visuales y tamaños predefinidos garantizando áreas táctiles y estilos de foco accesibles.

## Funciones

### Button
**Elaboración:** 2026-09-19 | **Actualización:** 2026-09-19

Renderiza un botón nativo aplicando dinámicamente las clases CSS generadas por `buttonClasses` según la variante y tamaño indicados.
