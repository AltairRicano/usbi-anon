Formulario para la creación de niveles de detección de noticias falsas (Fake News). Exige la definición del título, contenido, indicador explícito de veracidad (real o falsa) y la fuente/referencia obligatoria para fundamentar la respuesta, permitiendo agregar opcionalmente explicaciones e imágenes.

## Funciones

### FakeNewsForm
**Elaboración:** 2026-09-19 | **Actualización:** 2026-09-19

Gestiona el listado de elementos de noticias, permitiendo configurar el contenido, estado de veracidad y referencias requeridas para cada artículo.
