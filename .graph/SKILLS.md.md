Guía operativa para Claude Code que define las herramientas, agentes y guardrails asignados a cada bloque del plan de maduración (M1–M5). Establece reglas estrictas e invariantes como prohibir la recolección de PII, mantener secretos fuera del repositorio, preservar la estructura de claves foráneas de levels(id) y documentar lecciones aprendidas de errores técnicos y de seguridad previos.
