Define la especificación formal del contrato de la API HTTP versionada y los endpoints de salud del backend Go. Especifica que el XP es recalculado 100% por el servidor ignorando valores del cliente, que el puntaje del minijuego no tiene límite superior en la validación, y que el borrado de secciones o niveles exige dos pasos (archivado previo y eliminación física posterior).
